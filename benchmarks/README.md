# POLLICINO Benchmarks

Benchmark categories will include:

- plain text,
- source code,
- JSON/XML/CSV and structured data,
- uncompressed/raw media or binary formats where appropriate,
- already-compressed files,
- encrypted/random-looking data where legally and methodologically appropriate,
- cryptographically generated random bytes as a mandatory negative control.

Every comparison must distinguish:

1. payload size,
2. shared model/checkpoint size,
3. amortized model cost,
4. encode/decode compute,
5. exact round-trip correctness.

Classical compressor versions and exact command settings must be recorded.
