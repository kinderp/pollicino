## Three strongest next experiments

1. **UC-201 — Relay retirement:** critical for the eventual student-node fleet; ensures verified queue migration rather than pretending an offline node safely surrendered custody. Software: fault-injected queue simulation. Physical: 4–6 school-owned LoRa nodes + storage endpoints.
2. **UC-202 — Controlled forwarding faults:** separates radio loss, queue refusal and deliberate application-layer dropping only when the injected ground truth is known. Software: fault-classification confusion matrix including UNKNOWN. Physical: 4–8 school-owned boards at supervised checkpoints.
3. **UC-203 — Optical fallback:** an inexpensive cross-bearer recovery mode when no radio connection is possible at a handoff. Software: QR encode/decode and exact-hash verification without any network. Physical: first phones/laptops/printer, then 4–6 LoRa boards for subsequent relay.

UC-204 is an interdisciplinary science trial; UC-205 links PollicinoNet to AI/dataset governance and can remain software-first.

## Province of Messina controlled rollout

Start on school property with abstract checkpoint names `ME-SCHOOL`, `VF-SCHOOL`, `RM-SCHOOL`, `VN-SCHOOL`; these do **not** represent established radio links or validated coverage. Move only between sites with permission and supervision. Use temporary test identities, no home addresses and no student tracking. For cross-site tests record packet/bundle intent, actual observed TX/RX evidence, eligible holder write verification, missed contact windows and unknown/missing logs separately. Compare simulations and field recordings without conflating them.

## Required measurement plan

- **UC-201:** persistent-queue inventory, transfer complete hash, verified handoff receipt, unresolved/lost count, actual contact duration.
- **UC-202:** ground-truth injected fault, TX/RX counters from independent devices, receipt completeness, false-positive rate, confusion matrix.
- **UC-203:** scan completion, decoded full-object checksum, lighting/focus conditions and elapsed time (USB/Wi-Fi as baselines).
- **UC-204:** witnessed physical sample ID and manifest, documented clock uncertainty, exact joins vs unknown/mismatches.
- **UC-205:** operation approval/rejection with exact policy versions, evidence of delayed revocation delivery, zero real-person datasets.

Check applicable Italian/EU radio limits for **the exact configured LoRa frequency, power, antenna and duty cycle** before deploying; LoRaWAN regional parameter documents are contextual, **not proof that custom Pollicino PHY is LoRaWAN compliant**.
