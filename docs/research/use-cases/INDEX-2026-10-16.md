Top three: UC-212 for the multi-bearer network core, UC-211 for scientific validity of a student field test, UC-215 for a tangible robot data-mule demonstration.

Suggested physical order: UC-211 at fixed school checkpoints with 4–8 boards; UC-212 using 4–8 boards plus two host gateways; UC-215 as a supervised slow bench rover demonstration. UC-213 needs NFC readers/tags; UC-214 needs enclosure sensors. The planned Messina/Villafranca/Rometta/Venetico/Spadafora network uses only authorized public or school checkpoints and temporary experimental IDs.

No radio range, PDR, throughput, power or coverage result is claimed. PHY LoRa remains frozen and no software tests have yet been run. Emergency and robotics applications remain controlled educational experiments.
