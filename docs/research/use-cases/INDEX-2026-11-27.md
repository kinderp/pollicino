## Sequenza di sperimentazione
1. Simulare UC-346 con ledger per occorrenza e blob store; poi banco A→B→C su contatti disgiunti (UC-321), includendo code eleggibili (UC-343). Misurare accettazione applicativa e conteggio eventi separatamente.
2. Riutilizzare il trasporto per UC-347 con record di visita piccoli, verificando che gli arrivi tardivi restringano un intervallo solo quando giustificato.
3. UC-348: trasporto di manifest di revisione su LoRa e trasferimento di media via bearer ricco/USB, separati in registro; riesaminare sottotitoli sul video esatto.
4. Estendere eventualmente a checkpoint autorizzati nelle scuole di Milazzo, Venetico, Rometta, Spadafora e, se disponibile, sito scolastico più elevato. Relay volontari senza itinerari individuali. Nessuna copertura, partecipazione o collaborazione presunta.

I documenti descrivono bearer, attori, privacy, criteri e fonti. LoRa solo per informazioni compatte entro limiti esistenti; DISCOVERY non prova identità, EXACT richiede verifica, SEMANTIC non è lossless. Nessun software implementato o test eseguito in questa aggiunta. Nessuna misura fisica, nessuna modifica a PHY LoRa congelato, MAC, firmware o driver.
