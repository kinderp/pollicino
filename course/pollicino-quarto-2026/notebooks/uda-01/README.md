# Notebook UDA 1

`pollicino-uda01-lab.ipynb` è il notebook dimostrativo comune alle quattro lezioni.

Non sostituisce le activity: serve per proiezione in classe, esperimenti guidati e recupero. Usa solo la libreria standard Python e non contiene output salvati, così ogni classe rigenera i risultati.

Se Jupyter non è disponibile, tutti gli stessi concetti sono riproducibili con gli script nelle cartelle `activities/uda-01/l01` ... `l04`.
